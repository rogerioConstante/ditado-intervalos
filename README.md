# Ditado de Intervalos

Exercício de reconhecimento de **intervalos harmônicos** em pequenos
contrapontos a duas vozes, gerados automaticamente.

### ▶ [Abrir o ditado no navegador](https://rogerioconstante.github.io/ditado-intervalos/)

Funciona em qualquer navegador moderno, sem instalação (é preciso estar
conectado à internet para carregar os timbres).

![Tela do exercício](https://github.com/user-attachments/assets/1c3c4e42-acb8-4b73-b605-25ecfc00429e)

## Como funciona

- Cada exercício tem **10 questões**; em cada uma, um contraponto a duas
  vozes de 2 a 6 compassos.
- A questão aparece com **partitura e áudio** ou **somente áudio**.
- Escute com atenção; quando disponível (conforme o nível), repita o áudio
  com **Tocar**.
- Preencha os campos com os intervalos correspondentes. **Resposta** mostra a
  solução e **Próximo** passa à questão seguinte.
- O **nível** define a dificuldade, e o **timbre** pode ser escolhido entre
  piano, cordas, coral, órgão, flauta e outros.
- Ao final, o programa salva um relatório (`Ditado_Intervalos.txt`) com o
  desempenho, que pode ser entregue ao professor.

## Usar no próprio computador

Baixe o repositório (**Code ▸ Download ZIP**), descompacte e abra o
`index.html` no navegador (com internet, para os timbres).
